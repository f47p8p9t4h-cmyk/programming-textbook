Құжаттағы атаулар мен оқу жүктемесі силлабуста көрсетілген нұсқа бойынша берілді.

ПӘН ТУРАЛЫ ЖАЛПЫ МӘЛІМЕТ

Оқытушы:
Найзагараева Айгүл Аманжолқызы
PhD, аға оқытушы

Пәннің мақсаты

Web-технологияларды, Интернетке қатынау технологияларын, web-серверлерді, статикалық және динамикалық сайттарды, қолданбаларды бағдарламалауды және Web-бағдарламалау жобаларын жобалауды меңгеру.

Оқу нәтижелері

  • IPv4/IPv6 және IP-туннельдерді түсіну;
  • браузер мүмкіндіктерін және сайт құрылымын қолдану;
  • HTML, CSS, JavaScript, HTML5, Ajax, jQuery, XML технологияларын пайдалану;
  • PHP/PHP7, YII/Laravel және SQL, MySQL/PostgreSQL негіздерін қолдану;
  • академиялық адалдық пен AI құралдарын этикалық қолдану талаптарын сақтау.

ДӘРІСТЕР • 1–5 АПТА

1. Web-бағдарламалаудың негіздері. Web стандарттары және олардың эволюциясы.
2. Интернеттегі коммуникация моделі. Pull/Push модельдері.
3. Интернетке қатынау. Last mile, коммутация, модем.
4. Интернетке қатынау технологиялары: DSL, ISDN.
5. Web-серверлер. Web-сервер жұмысының механизмі. Статикалық және динамикалық беттер. CGI технологиясы. Скриптер.
Дәрістер Web-технологиялардың негізінен бастап серверлік технологияларға дейін бірізді түрде жүргізіледі.
6

ДӘРІСТЕР • 6–10 АПТА

6. Web-ресурстарды іздеу. Кэштеу. Proxy.
7. Іздеу технологиялары.
8. Интернет қызметтері. Электрондық пошта.
9. FTP және файлдармен алмасу.
10. Интернеттегі деректерді қорғау. Электрондық цифрлық қолтаңба. Криптография. Симметриялық және асимметриялық кілттер.
7

ДӘРІСТЕР • 11–15 АПТА

11. Пайдаланушыны идентификациялау. Cookies.
12. Фреймдер. HTML мультимедиасы. Формалар.
13. CSS: inline, external және бірнеше HTML файлдарымен жұмыс. CSS қасиеттері. Positioning және z-index.
14. JavaScript: литералдар, айнымалылар, өрнектер, скриптер, функциялар, циклдер, объектілер, мұрагерлік, браузер объектілері және оқиғалар.
15. Web-қосымшаның интерфейсі. HTTP. Perl-ге кіріспе. PHP негіздері, синтаксисі және операторлары.
8

ЗЕРТХАНАЛЫҚ ЖҰМЫСТАР • 1–5

  1. Visual Studio Code орнату.
  2. HTML-ге кіріспе. Негізгі элементтер.
  3. HTML кестелері.
  4. HTML тізімдері.
  5. Формалар, мультимедиа, frame/iFrame.

Практикалық бағыт

Зертханалық сабақтарда студент Web-бетті кезең-кезеңімен құрады: редакторды дайындау, HTML құрылымын жасау, кестелер мен тізімдерді орналастыру, кейін формалар мен мультимедиалық элементтерді қосу.

БАҒАЛАУ КРИТЕРИЙЛЕРІ

  • HTML5 және CSS3 арқылы семантикалық құрылым құру;
  • responsive design қағидаларын қолдану;
  • JavaScript көмегімен DOM-пен жұмыс жасау;
  • оқиғаларды, массивтерді, объектілерді және функцияларды пайдалану;
  • API, Promise, async/await сияқты заманауи JavaScript мүмкіндіктерін түсіну;
  • Web-қосымшаның құрылымы мен интерфейсін дұрыс ұйымдастыру.

Бағалау кезінде жұмыстың дұрыстығы, құрылымы, технологияларды қолдануы және тапсырманың талаптарға сәйкестігі ескеріледі.
