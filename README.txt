WEB бағдарламалау — Силлабус кітапша

Файлдар:
- index.html — негізгі кітап
- style.css — дизайн
- script.js — бет аудару

Іске қосу:
1. Үш файлды бір папкада сақтаңыз.
2. index.html файлын Chrome/Edge арқылы ашыңыз.
3. Беттің оң жағын бассаңыз — келесі бет, сол жағын бассаңыз — алдыңғы бет.
4. Пернетақтадағы ← және → батырмалары да жұмыс істейді.

Жоба HTML + CSS + JavaScript арқылы жасалған.
Мазмұн жүктелген WEB бағдарламалау силлабусының құрылымы мен тақырыптарына негізделген.
